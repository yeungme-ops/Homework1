# AISCI-210-F26-Homework1
Public template repository for Homework 1.

(If you haven't already, this would be a good time to get verified for [GitHub for Education](https://github.com/settings/education/benefits), which should provide access to more computational resources in Codespaces.  Tip from other students: be sure your documentation includes your name and shows the date.)

* Create your own repository using this one as a template.  We recommend creating a *private* repository.
* Open the repository in a Codespace.
* Select the `.venv` Python environment for the kernel of your Jupyter notebook (which should be automatically created by the Codespace thanks to the instruction in `devcontainer.json`) .
* Follow the instructions in the Homework 1 notebook.
* When you're finished, submit the homework on Gradescope.  Here are instructions for [linking your GitHub account to Gradescope](https://guides.gradescope.com/hc/en-us/articles/21587275611533-Linking-and-Unlinking-Accounts), and please note that it says for this initial linking, you must access Gradescope directly, not via the link from our Canvas homepage.  (This is my first time using a GitHub repository for submitting an assignment on Gradescope.  I won't update this repository with updates to those instructions (because those updates would not propagate to your own existing copies), so please watch Canvas Announcements for any potential clarifications or further instructions from me or Luke.)
* To stop the Codespace after you've committed your changes and pushed them to GitHub, I open the command palette and choose `Codespaces: Stop Current Codespace`.
